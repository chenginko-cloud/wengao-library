# 全部文稿总库

把 6 份各自独立的文稿阅读页汇总成一个总库：**2582 篇 / 646 万汉字**，全部正文内嵌，离线可用、无需后端。

## 线上地址

- 入口（自动识别设备）：https://chenginko-cloud.github.io/wengao-library/
- 强制桌面版：`?v=desktop` · 强制手机版：`?v=mobile`

## 目录结构

```
index.html      设备识别入口：手机/平板 → mobile.html，电脑 → desktop.html
desktop.html    桌面版：左侧 322px 常驻筛选栏 + 列表 + 右侧滑入阅读层
mobile.html     手机版：单列列表 + 左侧抽屉筛选 + 全屏阅读 + 左边缘滑动返回
```

两份界面是独立编写的，不是同一套响应式布局。首次打开需加载约 13MB（含全部正文），之后走浏览器缓存。

## 技术说明

- 单文件、零外部依赖；元数据明文内嵌，正文经 gzip + base64 内嵌，浏览器端用
  `DecompressionStream("gzip")` 在首次阅读时解压（约 2–4 秒）。
- 本仓库只存放构建产物；数据流水线（抽取 → 归一化 → 主题映射 → 注入 → 无头校验）在本地 `work/` 目录。
